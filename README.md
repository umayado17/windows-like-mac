# windows-like-mac

Macの「余計な動き」を止めて、Windowsの感覚に寄せるための設定プロンプトです。

Windows上がりでMacを使い始めた人が引っかかる動き——ウインドウを掴んだら
勝手に画面いっぱいに広がる、Dockが隣のモニターへ逃げる、デスクトップを
クリックしたらウインドウが全部退く、ホイールの向きが逆——を、自分の
Claude（Muse）に画面操作で止めてもらいます。

## 使い方

前提: MuseのMacアプリで、自分のMacとのペアリングとコンピュータ操作が
使えること。

1. [PROMPT.md](PROMPT.md) の全文をコピーして、自分のClaudeに貼る
2. 最初にモードを選ぶ
   - **対話モード**: 候補を1機能ずつ「今の設定」と「変えると何が起きるか」を
     確認しながら選び、最後にまとめてClaudeが変更する
   - **おまかせモード**: 発案者の設定一式（プリセット）を1回確認して、
     まとめてClaudeが変更する
3. 途中で承認カードが出たら許可する。終わると、変更前→変更後と
   戻し方が入った変更ログが返ってくる

ターミナルは使いません。全部「システム設定」の画面操作で変更します。

## プリセットの中身（おまかせモード）

- ウインドウのタイル表示（端・メニューバーへのドラッグ）をオフ
- タイトルバーのダブルクリックで拡大しない
- 壁紙クリックでデスクトップ表示を止める
- Dockの拡大と自動表示／非表示をオフ
- 「ディスプレイごとに個別の操作スペース」をオフ（Dockが別モニターへ移らない）
- ホットコーナーを四隅すべてなしに
- ナチュラルスクロールをオフ（ホイールがWindowsと同じ向き）
- ページ間スワイプ、スマートズームをオフ
- Finderでパスバーとステータスバーを表示、拡張子を常時表示
- 文頭の自動大文字と、スペース2回でピリオドをオフ

## あえて入れていないもの

プリセットは「全部オフ」ではありません。次の4点は発案者が意図的に
オンのままにしているので、おまかせモードでは触りません。
対話モードでのみ、本人の選択で変えられます。

- 操作スペースの自動並べ替え
- 英字入力中にスペルを自動変換
- スマート引用符とスマートダッシュ
- マウスポインタをシェイクして見つける

## ターミナルで一括設定したい人へ

[windows-like-mac.sh](windows-like-mac.sh) に同じ内容の `defaults`
コマンド版があります。Claudeに任せず自分で流す人向けです。
中身を確認してから実行してください。

## 検証環境と注意

- 検証済み: macOS 27.2.1（iMac、Mac Studio）。項目名や場所は
  macOSのバージョンで多少変わります。その場合はClaudeが
  「このMacには無い」と報告して次へ進む設計です
- どの項目も「システム設定」の同じ場所で元に戻せます
- セキュリティやプライバシーの設定は対象外です。プロンプト側でも
  触らない決まりになっています
